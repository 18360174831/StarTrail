# StarTrail 🌟

追星日记平台 - 记录追星日常、管理偶像信息、社区互动

## 项目结构

```
StarTrail/
├── frontend/    # 前端项目 (React 18 + TypeScript + Vite + Ant Design Mobile)
├── backend/     # 后端项目 (Node.js + Express + SQLite)
└── README.md
```

## 技术栈

- 前端：React 18 + TypeScript + Vite + Ant Design Mobile + Tailwind CSS
- 后端：Node.js + Express + SQLite
- 地图：ECharts 中国地图组件
- 部署：Docker

## 核心功能

- 用户注册/登录
- 追星日记发布与互动
- 偶像管理与关注
- 地图足迹打卡
- 倒数日卡片
- 社区广场
- 消息通知

## 开发规范

- 前后端分离开发
- 每次修改必须 commit
- 接口遵循 RESTful 规范
